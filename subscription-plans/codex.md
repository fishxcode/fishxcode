# Codex 系列套餐

Codex 系列按 **额度 + 有效期** 管理，常见形态包括包月、包周、包日。购买后系统会自动生成对应的套餐访问令牌，可直接使用，也可以在令牌管理中基于套餐创建子令牌给团队或他人使用。

查看当前在售 [Codex 系列套餐](https://fishxcode.com/pricing?currency=CNY&tab=subscription-plans&plan_series=codex)

## 一、套餐说明

- 套餐包含可用额度和有效期。
- 到期后套餐权益失效。
- 额度是否按日、按周、按月或自定义周期重置，以套餐配置为准。可在套餐管理取消每日套餐使用限制，消耗总额度。
- 支持团队管理和多人使用。不同额度的套餐适用于不同规模和使用强度的团队。
- 团队或他人通过基于套餐创建的令牌调用时，会一并计入套餐总额度。
- 套餐可提供发票。

## 二、计费口径

- **套餐额度**：套餐内可使用的额度总量或周期额度。
- **有效期**：包月、包周、包日等时间限制。
- **重置规则**：可以不重置，也可能按天、周、月或自定义周期重置。
- **适用范围**：套餐可用的模型、分组和接口类型，以套餐页为准。
- **令牌消耗**：自动生成的套餐令牌，以及基于套餐创建的团队令牌，都会消耗该套餐额度。

## 三、购买前确认

- 套餐有效期。
- 套餐总额度和周期额度。
- 当前工具使用的模型是否在套餐范围内。
- 套餐权益、可用模型、分组、重置规则和售后规则。
- 套餐额度是否匹配团队规模、成员数量和预期使用强度。
- 是否需要给团队成员或其他服务单独创建令牌，并设置令牌额度和过期时间。

## 四、购买和续费入口

[codex系列套餐](https://fishxcode.com/pricing?currency=CNY&tab=subscription-plans&plan_series=codex)

用户可以在 **套餐管理列表** 和 **套餐管理详情** 中购买 Codex 系列套餐。进入购买页后，先确认套餐权益、有效期、额度、开放购买时间、支付方式和购买须知，再完成支付。

![购买订阅套餐示例](/img/plans/buyplan.png)

续费需要同时满足以下条件：

- 套餐仍然有效。
- 套餐未下架。
- 套餐开启了可续费。
- 当前时间处于套餐允许的续费窗口内。

通常情况下，套餐到期前 3 天内可以续费；套餐到期后令牌不可用，需要重新购买或联系售后处理。具体续费窗口以套餐页面展示为准。

## 五、优惠码

如果有优惠码，可以在购买时输入并校验。优惠码只在校验通过且当前支付方式支持时生效；以购买页最终展示的应付金额和优惠规则为准。

## 六、支付后自动生成套餐令牌

支付成功后，系统会在 [控制台 → 令牌管理](https://fishxcode.com/console/token) 自动生成一个套餐访问令牌。令牌名称前缀为：

```text
Subscription Access - 套餐id
```

该令牌会绑定本次购买的套餐，用于消耗套餐额度和继承套餐有效期、分组、模型限制等规则。

![令牌管理中的套餐令牌示例](/img/plans/tokens.png)

## 七、基于套餐创建团队令牌

购买者可以在 [控制台 → 令牌管理](https://fishxcode.com/console/token) 基于套餐创建新的令牌，用于团队成员、项目服务或其他使用方。

创建时重点确认：

- **基于套餐创建**：选择对应的订阅套餐。
- **名称**：用于区分成员、项目或服务。
- **令牌分组**：默认使用用户分组，也可以按管理需要选择分组。
- **过期时间**：控制该令牌可使用到什么时候。
- **新建数量**：批量创建时会在名称后自动添加随机后缀。
- **套餐令牌额度**：限制该令牌最多可消耗的套餐额度。

团队令牌的消耗会计入原套餐总额度。建议给不同成员、项目或服务创建独立令牌，便于后续按令牌统计、限制和排查。

![基于套餐创建令牌示例](/img/plans/create.png)

## 八、查看使用日志和团队指标

套餐令牌和团队令牌的使用记录可以在 [控制台 → 使用日志](https://fishxcode.com/console/log) 查询。排查单次请求时，优先按时间、模型、Token、分组、请求 ID 或状态码筛选；字段含义可参考 [错误日志说明](/error-logs)。

团队相关指标可以在 **使用日志 → 分组健康状态** 查看。该视图可以按分组、用户、令牌维度统计请求数、成功率、消耗、缓存命中、平均耗时和最近请求时间，适合判断套餐下不同团队成员或服务的使用情况。详细字段说明可参考 [分组健康状态](/group-health)。

![分组健康状态示例](/img/plans/statistics.png)

## 九、到期与上限

套餐时间过期后，该套餐关联的自动生成令牌和基于套餐创建的团队令牌都会不可用。

达到周期额度上限后，可以在套餐管理中取消套餐上限，让后续请求继续消耗套餐总额度。是否可取消、取消后如何生效，以套餐管理页面展示为准。

如果已经消耗完套餐总额度，建议联系我们进行直接续费，优先沿用当前套餐和原有令牌。直接续费可以避免重新购买套餐后生成新的 Key，减少团队成员、项目服务和客户端配置中的 Key 更新成本。

仍在续费窗口内且套餐支持续费时，可以续费当前套餐；不满足续费条件时，需要重新购买或联系售后确认是否可直接续费。

## 十、退款说明

退款规则以购买页、套餐说明和 [退款政策](/refund) 为准。遇到交付、令牌或额度异常时，请提供订单号、套餐名称、令牌名称、请求时间和请求 ID，便于排查。

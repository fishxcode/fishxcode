# Claude 系列套餐

Claude 系列通过 [ClaudeMax](https://claudemax.fishxcode.com/) 提供 Claude Max 订阅协助和 Claude Code 托管服务。它面向想稳定使用 Claude Code 的中文开发者，解决支付、账号状态、网络和本地环境配置问题。

## 一、解决的核心问题

很多用户不是不会用 Claude Code，而是卡在开通和稳定使用前的基础条件：

- **美区支付门槛**：没有 SSN / ITIN，国内卡容易风控，找代付费率高且不稳定。
- **账号状态不稳定**：自行注册或临时渠道可能遇到风控、订阅中断、售后不清晰，影响长期开发节奏。
- **网络访问不稳定**：Anthropic 直连可能出现 `403`、超时或连接质量波动，VPS 默认线路也可能对 API 不稳定。

ClaudeMax 的处理方式是：代为完成 Claude Max 订阅，预装 Claude Code 环境，配置低延迟中转，并提供本地项目挂载工具。用户拿到连接信息后，通过 SSH 进入服务器即可开始使用 Claude Code。

## 二、套餐说明

- 这是官方号订阅权益，不是普通余额按量扣费。
- 套餐面向 Claude Code 使用场景，包含 Claude Max 订阅协助、海外服务器、低延迟中转和 Claude Code 环境。
- 常见套餐包括 ClaudeMax x5 和 ClaudeMax x20。个人使用通常选择 ClaudeMax x5；团队、重度使用、长会话和团队 PoC 通常选择 ClaudeMax x20。
- 账号个人独享，不与他人共用；用量归购买者使用。
- 可支持本地项目挂载，便于本地代码与服务器代码双向同步。
- 支持开具发票。
- 可用模型、次数、有效期、交付方式、开通时间、售后和保障规则，以购买页展示为准。

## 四、订阅流程

1. 打开 [ClaudeMax](https://claudemax.fishxcode.com/) 或 FishXCode 订阅套餐页。
2. 选择 ClaudeMax x5、ClaudeMax x20 或页面展示的其他 Claude 系列套餐。个人使用优先看 x5；团队或重度使用优先看 x20。
3. 确认套餐包含内容、有效期、账号保障、开通方式、发票和售后规则。
4. 完成支付。
5. 按页面、站内通知或客服消息获取交付信息。常见交付内容包括服务器连接方式、SSH 使用方式、卡密或其他开通说明。
6. 使用 SSH 进入托管服务器，运行预装的 Claude Code 环境开始开发。
7. 如需编辑本地项目，可按页面说明使用本地项目挂载工具，将本地代码与服务器环境同步。

标注为人工发放或需提前预定的套餐，需要等待管理员处理。页面展示的 30 分钟内开通、提前预定联系等说明，以购买页实际状态为准。大量订购请提前预约联系，避免库存、服务器和账号交付排期影响使用。

## 五、与自己订阅的区别

| 项目 | 自己订阅 Claude Max | ClaudeMax |
| --- | --- | --- |
| 支付条件 | 需要自行处理海外支付、手机号或账号条件 | 由服务方协助订阅 |
| Claude Code 环境 | 自己安装、维护和排障 | 服务器环境预装，SSH 直连使用 |
| 网络连接 | 自行处理直连、代理或 VPS 线路 | 包含低延迟中转 |
| 账号状态 | 官方规则和账号异常自行处理 | 按页面规则提供账号异常或订阅中断保障 |
| 成本结构 | 官方订阅费之外，还可能需要服务器和中转成本 | 套餐价格包含 Max 订阅、服务器和中转 |

## 七、适用场景

- 不方便使用美区支付或海外账号条件的开发者。
- 想快速使用 Claude Code，不想自己安装和维护环境的用户。
- 需要更稳定网络连接和低延迟访问 Anthropic 的用户。
- 需要本地项目挂载、远程编辑和长期开发环境的个人或小团队。
- 希望有发票、售后和账号异常保障的企业或团队用户。

## 八、安全性和服务器交付

ClaudeMax 交付的是独立服务器环境和账号使用环境，用户通过 SSH 进入服务器使用 Claude Code。若对应服务器支持转让，可以按售后规则协助转让服务器或使用权，具体以实际交付形态和页面说明为准。

请妥善保管服务器连接信息、卡密、账号信息和相关凭证，不要公开转发给无关人员。

## 九、转让、封号和退款

- Claude 系列按 Claude 工具链和 ClaudeMax 托管服务使用，不按通用余额处理。
- 不同套餐对应的账号权益、使用强度、稳定性保障和可用模型可能不同。
- 套餐交付后请妥善保存连接信息、卡密、账号信息或相关凭证，不要公开转发。
- 如果服务器、订阅状态或账号状态异常，请按页面售后规则联系支持处理。

转让规则：

- 首次转让免费。
- 第二次及以后转让，每次收取 50 元服务器费用。
- 是否可转让，取决于具体服务器、账号和交付形态；以客服确认结果为准。

封号和退款规则：

- 如果账号异常或封号符合保障范围，可以按剩余未使用天数比例退款。
- 示例：套餐已使用 10 天，剩余 20 天，则按剩余 20 天对应额度退款。
- 如果希望继续使用，可以补齐已使用 10 天对应的费用，由我们重新开新号继续交付。
- 如果因非法用途、违规使用或不合理使用导致封禁，不予退款。请合理、正规使用 ClaudeMax 和 Claude Code。

# Planes Claude

Los planes Claude se ofrecen mediante [ClaudeMax](https://claudemax.fishxcode.com/), con asistencia para suscripción Claude Max y alojamiento de Claude Code. Están pensados para desarrolladores que quieren usar Claude Code de forma estable y resolver pagos, estado de cuenta, red y configuración local.

## 1. Problemas que resuelve

- **Barrera de pago en EE. UU.**: sin SSN / ITIN, tarjetas locales con controles de riesgo y pagos intermediados caros o inestables.
- **Estado de cuenta inestable**: cuentas registradas por cuenta propia o canales temporales pueden sufrir controles, interrupciones o soporte poco claro.
- **Red inestable**: Anthropic directo puede devolver `403`, tiempos de espera o fluctuaciones; rutas VPS por defecto también pueden ser inestables.

ClaudeMax gestiona la suscripción Claude Max, preinstala Claude Code, configura una línea de baja latencia y ofrece herramienta de montaje de proyecto local. Con los datos de conexión, entras por SSH y usas Claude Code.

## 2. Descripción del plan

- Es un beneficio de suscripción de cuenta oficial, no saldo por consumo.
- Incluye asistencia de suscripción Claude Max, servidor extranjero, línea de baja latencia y entorno Claude Code.
- Los planes comunes son ClaudeMax x5 y ClaudeMax x20. Uso individual: normalmente x5; equipos, uso intensivo, sesiones largas y PoC de equipo: normalmente x20.
- Cuenta dedicada, no compartida. El uso pertenece al comprador.
- Admite montaje de proyecto local para sincronizar código local y servidor.
- Se puede emitir factura.
- Modelos, conteos, validez, entrega, activación, soporte y garantías siguen la página de compra.

## 4. Flujo de suscripción

1. Abre [ClaudeMax](https://claudemax.fishxcode.com/) o la página de planes de FishXCode.
2. Elige ClaudeMax x5, ClaudeMax x20 u otro plan mostrado. Para uso personal mira x5 primero; para equipos o uso intensivo mira x20 primero.
3. Confirma beneficios, validez, garantía de cuenta, activación, factura y soporte.
4. Completa el pago.
5. Recibe información de entrega mediante la página, notificación interna o soporte. Normalmente incluye conexión del servidor, uso SSH, código de tarjeta u otras instrucciones.
6. Entra al servidor por SSH y usa el entorno Claude Code preinstalado.
7. Si necesitas editar un proyecto local, usa la herramienta de montaje indicada para sincronizar el código.

Los planes con entrega manual o reserva previa requieren procesamiento del administrador. Para compras en volumen, contacta antes para confirmar inventario, servidores y calendario de activación.

## 8. Seguridad y entrega del servidor

ClaudeMax entrega un entorno de servidor independiente y un entorno de cuenta. El usuario entra por SSH para usar Claude Code. Si el servidor entregado permite transferencia, se puede transferir el servidor o derecho de uso según las reglas posventa.

Guarda de forma segura conexión, códigos, cuenta y credenciales. No los publiques ni reenvíes a personas no relacionadas.

## 9. Transferencia, bloqueo y reembolso

Reglas de transferencia:

- La primera transferencia es gratuita.
- La segunda y posteriores cuestan CNY 50 por transferencia como tarifa de servidor.
- La posibilidad de transferencia depende del servidor, cuenta y forma de entrega; prevalece la confirmación de soporte.

Reglas de bloqueo y reembolso:

- Si el problema o bloqueo entra en la garantía, el reembolso se calcula por días no usados.
- Ejemplo: usado 10 días y quedan 20 días; se reembolsa según los 20 días restantes.
- Si quieres seguir usando el servicio, puedes pagar los 10 días usados y se crea una cuenta nueva.
- Si el bloqueo se debe a uso ilegal, infracción o uso no razonable, no hay reembolso. Usa ClaudeMax y Claude Code de forma legal y normal.

# Offres d'abonnement FishXCode

Cette page présente les points d'entrée, catégories et règles de facturation des offres d'abonnement FishXCode. Les prix, stocks, limites d'achat, durées de validité et limites périodiques dépendent de la page de tarification.

Liens utiles :

- [Toutes les offres](https://fishxcode.com/pricing?currency=CNY&plan_series=all&tab=subscription-plans)
- [Offres Claude](https://fishxcode.com/pricing?currency=CNY&tab=subscription-plans)
- [Offres Codex](https://fishxcode.com/pricing?currency=CNY&tab=subscription-plans&plan_series=codex)
- [Offres au nombre de requêtes](https://fishxcode.com/pricing?currency=CNY&plan_series=mixed&plan_sort=price_asc&tab=subscription-plans)

## 1. Catégories

| Série | Entrée | Description |
| --- | --- | --- |
| Claude | [Offres Claude](/fr/subscription-plans/claude) | Abonnement ClaudeMax et hébergement Claude Code |
| Codex | [Offres Codex](/fr/subscription-plans/codex) | Crédit + durée de validité, pour usage individuel ou équipe |
| Nombre de requêtes | [Offres au nombre de requêtes](/fr/subscription-plans/by-number-of-times) | Comptabilise les requêtes réussies pour les modèles Claude et Codex concernés |

## 2. Résumé des règles

- Les offres Claude sont des abonnements de compte officiel. Voir [Offres Claude](/fr/subscription-plans/claude).
- Les offres Codex reposent sur un crédit et une durée de validité, pas seulement sur un nombre de requêtes.
- Les offres au nombre de requêtes comptent les requêtes réussies. Les limites quotidiennes, mensuelles et totales dépendent de l'offre.
- Claude Opus 4.8 et GPT-5.5 comptent comme `2.5 × requêtes réussies réelles`.

## 3. Achat

1. Ouvrez la [page de tarification](https://fishxcode.com/pricing?currency=CNY&tab=subscription-plans).
2. Passez à “Subscription Plans”.
3. Filtrez par Claude, Codex ou nombre de requêtes.
4. Vérifiez prix, validité, crédit, nombre de requêtes, modèles, règles de réinitialisation et restrictions.
5. Après paiement, consultez l'état dans la console.
6. Si une Key est générée, copiez le Base URL et la Key indiqués et configurez-les dans l'outil concerné.

## 4. Notes

### Les prix suivent la page de tarification

Prix, stock, limites, remises et disponibilité peuvent changer. Ce document explique les règles; la page officielle fait foi.

### Tous les modèles ne coûtent pas 1 requête

Les offres au nombre de requêtes utilisent les requêtes réussies comme unité de base. Claude Opus 4.8 et GPT-5.5 comptent `2.5 × requêtes réussies réelles`.

### Codex et nombre de requêtes

Codex se concentre sur crédit et validité. Les offres au nombre de requêtes se concentrent sur les requêtes, limites quotidiennes, mensuelles et totales.

### Expiration ou limite atteinte

Après expiration, épuisement du crédit, du nombre total ou atteinte d'une limite, le système restreint l'utilisation selon les règles. Vous pouvez attendre le reset, acheter une nouvelle offre ou utiliser le solde.

### Problèmes d'utilisation

Vérifiez d'abord validité, limites et modèles pris en charge. Consultez ensuite [Journaux d'erreur](/fr/error-logs) et [État de santé des groupes](/fr/group-health). Pour le support, fournissez numéro de commande, heure et ID de requête.

# Claude Plans

Claude plans are provided through [ClaudeMax](https://claudemax.fishxcode.com/), which offers Claude Max subscription assistance and Claude Code hosting. They are designed for Chinese-speaking developers who want stable Claude Code access and need help with payment, account status, network access, and local environment setup.

## 1. Core Problems Solved

Many users can use Claude Code, but get blocked before they can start or use it reliably:

- **US payment barrier**: no SSN / ITIN, domestic cards may trigger risk controls, and third-party payment assistance can be expensive or unstable.
- **Unstable account status**: self-registered or temporary-channel accounts may run into risk controls, subscription interruptions, or unclear after-sales handling.
- **Unstable network access**: direct Anthropic access may return `403`, time out, or fluctuate. Default VPS routes can also be unstable for API access.

ClaudeMax solves this by handling the Claude Max subscription, preinstalling the Claude Code environment, configuring a low-latency relay, and providing a local project mount tool. After receiving connection information, you SSH into the server and start using Claude Code.

## 2. Plan Description

- This is an official-account subscription benefit, not regular balance-based billing.
- The plan is for Claude Code usage and includes Claude Max subscription assistance, an overseas server, low-latency relay, and Claude Code environment.
- Common plans include ClaudeMax x5 and ClaudeMax x20. Individual users usually choose ClaudeMax x5; teams, heavy usage, long sessions, and team PoCs usually choose ClaudeMax x20.
- The account is personally dedicated and not shared with others. Usage belongs to the buyer.
- Local project mounting is supported for two-way sync between local code and the server environment.
- Invoices are supported.
- Supported models, request counts, validity period, delivery method, activation time, after-sales rules, and guarantees are subject to the purchase page.

## 4. Subscription Flow

1. Open [ClaudeMax](https://claudemax.fishxcode.com/) or the FishXCode subscription plan page.
2. Choose ClaudeMax x5, ClaudeMax x20, or another Claude plan shown on the page. Individual users should check x5 first; teams or heavy users should check x20 first.
3. Confirm included benefits, validity period, account guarantee, activation method, invoice support, and after-sales rules.
4. Complete payment.
5. Receive delivery information through the page, in-site notification, or customer support. Delivery usually includes server connection details, SSH usage, card code, or other activation instructions.
6. SSH into the hosted server and start development with the preinstalled Claude Code environment.
7. If you need to edit a local project, follow the page instructions to use the local project mount tool and sync code with the server environment.

Plans marked as manually delivered or requiring advance reservation must wait for admin processing. Activation within 30 minutes, advance reservation, and similar notes are subject to the actual purchase page. For bulk purchases, contact support in advance to confirm inventory, server delivery, and activation scheduling.

## 8. Security and Server Delivery

ClaudeMax delivers an independent server environment and account usage environment. Users SSH into the server to use Claude Code. If the delivered server supports transfer, the server or usage right can be transferred according to after-sales rules, subject to the actual delivery type and page instructions.

Keep server connection information, card codes, account information, and related credentials private. Do not publicly forward them to unrelated people.

## 9. Transfer, Account Ban, and Refund

- Claude plans are used with the Claude toolchain and ClaudeMax hosted service, not regular balance billing.
- Account benefits, usage intensity, stability guarantees, and available models may differ by plan.
- Keep delivered connection information, card codes, account information, and credentials secure.
- If the server, subscription status, or account status is abnormal, contact support according to page after-sales rules.

Transfer rules:

- The first transfer is free.
- The second and later transfers charge a server fee of CNY 50 each time.
- Transfer availability depends on the specific server, account, and delivery type. Customer support confirmation prevails.

Account ban and refund rules:

- If an account issue or ban is within the guarantee scope, refund can be calculated by unused days.
- Example: if the plan has been used for 10 days and has 20 days left, the refund is based on the remaining 20 days.
- If you want to continue using the service, you can pay for the 10 used days and we will create a new account for delivery.
- If the ban is caused by illegal, violating, or unreasonable use, no refund is provided. Use ClaudeMax and Claude Code reasonably and lawfully.
